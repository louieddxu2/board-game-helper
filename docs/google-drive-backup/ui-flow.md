# Google Drive 備份 UI

## 入口與授權

Workspace drawer 提供「開啟 Google Drive 備份」，與本機 ZIP 匯出／匯入並列。開啟彈窗時，若在線且當次工作階段尚未授權，會啟動既有 GIS token flow；也提供「連結 Google Drive」供失敗或主動解除授權後重試。Google 授權使用 Google 的頁面，App 的訊息使用既有自訂 modal。

存取權杖只保存在頁面記憶體；重新載入需要重新授權。離線與主動解除授權時，不執行雲端操作或背景自動備份。

## 備份彈窗

標題為「Google Drive 備份」，顯示本機待備份狀態、上次備份時間及資料夾／表格數量。

- 「立即備份」上傳完整備份。
- 「選擇備份還原」尋找保留的版本。
- 已找到雲端版本時顯示「還原此備份」；尚未載入版本列表時，可按「選擇其他備份」。
- 如果最新雲端版本與本機備份紀錄不同，要求先還原或明確按「以本機資料覆蓋雲端」。單純選取較舊版本不視為雲端衝突。
- 「主動解除授權」停止當次工作階段的雲端操作。

彈窗說明保留最新 3 份備份，以及新備份成功後才將多餘舊檔移到垃圾桶。備份進度依序顯示讀取、產生檔案、逐表上傳、儲存索引、雲端確認及清理舊備份。只有確認索引發布成功後才記錄備份完成；清理延後或失敗時保留完成紀錄並顯示警告。

## 選擇與還原

1. 按「選擇備份還原」，載入最新 3 個保留版本。若只有 1 份，直接顯示該版本；若有多份，顯示「備份版本」選單、版本次序與時間。
2. 按「還原此備份」，下載並驗證剛才選取的版本。版本已失效或格式／表格 ID 不一致時顯示錯誤，保持本機資料。
3. 成功後進入既有「匯入整個資料庫」預覽。到這一步仍未改寫本機資料。
4. 使用者選「合併」或「取代」才提交 IndexedDB；也可以取消預覽。

不另設重複的還原確認彈窗，不使用原生 confirm()，也不在下載後自動覆蓋。舊版單一 Workspace XLSX 仍可還原，但不加入資料夾式 3 版本的清理範圍。

## 手機與 PWA

操作按鈕與版本選單使用現有 Workspace 表單樣式。以 390 × 844 手機視窗驗證彈窗不超寬，並驗證連續 4 次備份只留下 3 個版本、較舊版本可經預覽取代且重新載入後仍正確。

備份測試使用模擬 Drive，涵蓋上傳中斷與雲端確認失敗；不存取真實使用者的 Google Drive。OAuth、真實網路速度與帳戶權限仍需在實際工作階段觀察。
