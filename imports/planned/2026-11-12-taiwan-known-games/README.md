# 臺灣知名桌遊入庫紀錄

2026-11-12 確認清單上的 200 款皆對應至正式 D1 的公開主遊戲。匯入前以 BGG ID、已知版次、正規化名稱、原文名稱及別名比對既有資料。

| 狀態 | 款數 | 處理方式 |
| --- | ---: | --- |
| 原有公開主遊戲 | 41 | 沿用既有遊戲與 BGG 對應。其中 38 款已有至少一項屬性評分證據。 |
| 先匯入的 8 款 | 8 | 正式 D1 與公開目錄皆已核對。 |
| 其餘已匯入 | 151 | 包含原訂首批 24 款，以及《台北大空襲》與《2045》。 |

[完整清單](candidates.json)依研究排序保留 BGG ID、主名稱、原名、繁中別名、BGG 難度、臺灣佐證與入庫對應。`firstBatch` 保留原先規劃的首批範圍。原有遊戲的屬性覆蓋取自正式站目錄版本 12726。

有出版社、中文版次資料或通路明列繁中版本的品名，採為主名稱。`traditionalNameSource` 記錄來源。其他繁中用名存為可搜尋的 `traditionalAlias`，在屬性投票中顯示於原文主名稱下方。

BGG 難度是研究清單的選樣參考，可留空。正式 D1 的 `games` 與 `game_external_ids` 都沒有 BGG 難度欄位，匯入遊戲與建立屬性投票主體無須填寫。

## 2026-11-12 已匯入的 8 款

[匯入 SQL](sourced-names.sql)建立 8 筆公開主遊戲、8 筆主 BGG 對應、7 筆繁中別名。正式 D1 確認 8 筆投票主體各有 25 項啟用屬性的初始狀態。公開遊戲與屬性目錄分別在版本 858 與 12734 確認這批資料，英文主名稱的投票副標均與繁中別名一致。

正式 D1 執行這批匯入 SQL 讀取 3,534 列、寫入 1,958 列，包含觸發器與索引的開銷。匯入後逐筆查驗另讀取 1,493 列，目錄發布與公開 API 查驗未計入這些數字。

## 2026-11-12 匯入其餘 151 款

[匯入 SQL](remaining-games.sql)建立 151 筆公開主遊戲、151 筆主 BGG 對應及 75 筆繁中別名。正式 D1 逐筆查驗後，從公開目錄確認 151 款的主名稱、別名與投票副標。遊戲與屬性目錄分別推進至版本 1009 與 12885。每款建立 25 項屬性的初始狀態。

正式 D1 執行這批匯入 SQL 讀取 67,349 列、寫入 36,386 列。匯入後比對 200 款另讀取 11,441 列。完整 migrations 的本機試跑確認，既有遊戲資料保留，重跑寫入 0 列。

## 2026-11-13 原有遊戲補繁中別名

2026-11-13 的比對發現，8 款原有公開主遊戲的目錄名稱與研究清單用名不同，建立規則時用清單用名搜尋不到。[別名 SQL](existing-aliases.sql)為這 8 款加入 9 筆別名：機密代號、藍星、地球、卓爾金歷：瑪雅日曆、拼布對決、馬可波羅遊記、大五月花號、達爾文的旅程、詭鎮奇談卡牌版。每筆只在目標遊戲的 ID 與主名稱仍符合，且沒有任何遊戲名稱或別名已用同一正規化鍵時才寫入。

本機以完整 migrations 試跑時，其中 6 款存在，寫入 7 筆別名並排入遊戲目錄更新；重跑寫入 0 筆。匯入前的正式 D1 全表快照中，8 款目標的 ID 與主名稱皆符合，沒有任何遊戲或別名使用這 9 個鍵。

2026-11-13 與[第二批 35 款](../2026-11-13-taiwan-common-games/README.md)在同一個 D1 交易寫入正式 D1，9 筆別名全部寫入並已發布至公開目錄，用量合併記錄於第二批。
