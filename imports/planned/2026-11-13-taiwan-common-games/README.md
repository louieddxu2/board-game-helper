# 臺灣常見桌遊入庫紀錄（第二批）

2026-11-13 匯入 35 款臺灣常見桌遊，皆已建立正式 D1 的公開主遊戲。匯入前，這 35 款在正式 D1 的遊戲、別名與 BGG 對應中都比對不到，也不在[第一批 200 款](../2026-11-12-taiwan-known-games/README.md)的主 ID 或版次 ID 中。比對範圍包含非公開與已合併的遊戲。

## 來源與選樣

- 卡牌屋 BGG 排行對照頁（派對、家庭、抽象、策略、主題、總榜，共 467 個 BGG ID）。其中 295 款不在目錄中，取臺灣仍在售或僅暫時斷貨、且有繁中品名的基本遊戲，略過擴充、主題換皮版與兒童版。
- 排行榜沒有涵蓋的臺灣長青派對遊戲，例如德國心臟病、誰是牛頭王、終極密碼、嗒寶、閃靈快手和爆炸貓，從卡牌屋商品頁取得繁中品名與 BGG ID。
- 海底探險的卡牌屋繁中基本版商品頁已下架。BGG ID 169654 取自 Dice Tower 與 Board Game Directory 這兩個以 BGG ID 編目的網站；兩站的 Boost 版 ID 427866 與卡牌屋 Boost 商品頁的 BGG 連結一致。

## 主名稱規則

沿用第一批：卡牌屋商品頁標示繁體中文版、且連到同一 BGG ID 的品名採為主名稱，共 22 款。其餘 13 款只找到英文、簡中或多國語言版，或商品頁已下架，主名稱用 BGG 原文名，臺灣用名存為可搜尋的別名：

Da Vinci Code／終極密碼、One Night Ultimate Werewolf／一夜終極狼人、Deep Sea Adventure／海底探險、Captain Sonar／深海諜影、Tokaido／東海道、Imhotep／印和闐、Lost Cities／失落的城市、Jaipur／齋普爾、Hive／蟲蟲攻防戰、Blokus／大格鬥、SCOUT／馬戲星探、Calico／貓與花毯、War Chest／戰爭之匣。

另有 8 筆常見別名：達文西密碼、哆寶、Dobble、格格不入、聖家堂、骷髏與玫瑰、Take 6!、Geistesblitz。

## 2026-11-13 正式匯入

[匯入 SQL](import.sql)建立 35 筆公開主遊戲、35 筆主 BGG 對應、13 筆繁中別名及 8 筆常見別名，與第一批的[原有遊戲別名](../2026-11-12-taiwan-known-games/existing-aliases.sql)放在同一個 D1 batch 交易執行，之後以已發布程式共用的 `flushCatalogOutbox()` 發布目錄增量。沒有重播、重建快照或重新部署 Worker。

匯入前，完整 migrations 的本機資料庫試跑確認：既有遊戲資料保留，每款建立 25 項啟用屬性的初始狀態，重跑寫入 0 列。
