# 知名擴充入庫紀錄

2026-11-14 整理 15 款知名擴充。每款的主遊戲都已在正式 D1，且匯入前這些擴充的 BGG ID、名稱與別名都不在正式 D1，主遊戲底下也沒有同名的既有擴充。

## 擴充在兩個網站的單位

- **規則網站**：擴充不是獨立的遊戲單位。搜尋擴充名稱會找到它的主遊戲，擴充網址顯示主遊戲頁，規則存在主遊戲並以擴充為版本。
- **屬性投票**：擴充只以「主遊戲＋擴充」的組合投票。建立 `expansion_of` 關聯時，觸發器會建立組合並初始化 25 項屬性。組合名稱用精簡標籤，見 [migration 0122](../../../migrations/0122_concise_expansion_configuration_labels.sql)。

## 匯入 SQL

[匯入 SQL](import.sql)建立 15 筆公開擴充、15 筆主 BGG 對應、18 筆別名與 15 筆 `expansion_of` 關聯，再把組合標籤設為上表的精簡名稱。每一步都檢查主遊戲的 ID 與主名稱仍符合，且沒有其他遊戲或別名使用同一名稱或 BGG ID。

完整 migrations 的本機資料庫試跑確認：15 個組合可投票、各有 25 項屬性初始狀態，擴充沒有單獨的投票主體，遊戲目錄記錄主遊戲，既有遊戲資料不變，重跑寫入 0 列。

## 2026-11-14 正式匯入

匯入前讀取正式 D1 的遊戲、別名、BGG 對應與 12 款主遊戲的既有關聯，確認沒有衝突。SQL 以一個 D1 batch 交易執行，之後以已發布程式共用的 `flushCatalogOutbox()` 發布 15 筆遊戲與 30 筆屬性主題增量。沒有重播、重建快照或重新部署 Worker。

遊戲與屬性目錄分別從版本 1052 與 12948 推進至 1067 與 12978，outbox 清空。15 個組合皆可投票、各有 25 項屬性初始狀態，名稱與上表一致。從正式站公開目錄 API 套用增量，以建立規則頁的搜尋邏輯查詢 37 個擴充名稱、原文名與別名，第一筆皆為對應的主遊戲並標示擴充，沒有擴充以獨立遊戲出現；擴充網址也顯示主遊戲頁。

[migration 0122](../../../migrations/0122_concise_expansion_configuration_labels.sql)尚未部署。部署後，原有 4 款 BGG 擴充的組合名稱會改為精簡標籤，例如「馬拉開波＋起義擴」。
